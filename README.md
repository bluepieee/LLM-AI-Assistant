# 🤖 LLM AI Assistant

A beginner-friendly AI chatbot built using **Python** and the **OpenAI API**.

This project was created to learn the fundamentals of **Generative AI, Large Language Models (LLMs), API integration, prompt engineering, and conversation memory**.

## ✨ Features

- 💬 Interactive AI chat
- 🧠 Conversation memory during the current session
- 🎯 Custom prompt engineering
- 🧹 `clear` command to reset the conversation
- 🛑 `exit` command to close the assistant
- 🛡️ Basic API error handling
- 🔐 Secure API key management using `.env`

## 🛠️ Technologies

- Python
- OpenAI API
- python-dotenv
- Git & GitHub
